# 11단계 요청: 등산객용 오프라인 휴대폰 앱 (2026-11-24, 예린·언니)

> 우리 프로젝트에서 실행화면 제외하고 홈페이지나 앱을 만들 수는 없을까? 실제 등산객이 사용할 수 있는? 아니면 알림이 오는 기능을 수행하는?
> (언니) 홈페이지가 아니라 와이파이 없이도 실행할 수 있는 휴대폰 앱 같은 걸 만들어야 돼
> (예린) 근데 와이파이 없으면 실시간 위치를 어케 앎
> 불 났을 때 실시간 날짜나 날씨나 계절도 알아야 하는 거 아니야? / 데모 때 내 위치는 북한산이 아니라 학교인데?
> 오키 그럼 만들어줘!!

- AI 도구: Claude (claude.ai 대화 + GitHub 연동)
- 결정한 설계
  - GPS 는 인공위성 신호라 인터넷이 없어도 된다. 날짜·계절·낮밤도 휴대폰 시계로 안다.
  - 불이 난 곳은 밖에서 알려 줘야 한다(통신 필요). 숫자 몇 개라 문자·링크·QR 로 충분하고, 받은 뒤 계산은 휴대폰에서.
  - 날씨는 관제가 함께 보내고, 못 받으면 계절 평년 날씨로 추정.
  - C 엔진을 WebAssembly 로 컴파일해 휴대폰에서 실행 (주언어 C 조건 유지).
  - 학교 시연은 데모 모드(지도에서 위치 찍기, 시간 빠르게, 안내대로 걸어서 대피).
  - 기상청 인증키는 공개 앱에 넣지 않는다.
