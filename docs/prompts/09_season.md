# 9단계 요청: 사계절 날씨 특징 + 계절별 디자인 (2026-11-21, 예린)

> 경보 알림창이랑 종류별 산 모양을 언니가 하고, 내가 사계절 날씨 특징(장마는 제외, 봄/가을은 건조, 여름은 습함,
> 겨울은 건조하고 눈옴)을 하기로 했어. 새로운 브랜치 만들어서 고고
> 아 그리고 계절별 디자인도 해줘

- AI 도구: Claude (claude.ai 대화 + GitHub 연동)
- 브랜치: `season-weather` → Pull Request
- 범위
  - 계산(C): 계절 평년값(기상청 서울 1991~2020)으로 하루 동안의 기온·습도·바람 변화 생성, 겨울 눈(눈 위는 안 탐, 눈길은 느리게 걸음)
  - 화면(Python): 계절별 지도 색(봄 진달래, 여름 짙은 초록, 가을 단풍, 겨울 눈), 설정 패널의 "계절 평년 날씨" 선택, 계절 대표 날짜
- 언니 작업(경보 알림창, 산 모양)과 충돌을 줄이려고 새 기능은 되도록 새 파일(season.c/h, season_render.py)에 넣었다.
- 계절을 고르지 않으면(`season = none`) 기존 시나리오 결과가 그대로 나오도록 했다.
