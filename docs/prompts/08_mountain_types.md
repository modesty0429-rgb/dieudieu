# 실제 산 기능 요청 (feature/mountain-types, 2026-11-21)

> feature/mountain-types에 종류별 산 모양(기상청 데이터에 있는거. 북한산, 설악산, 지리산 등) 및 등산로 데이터 반영 기능을 넣고싶어

선택한 것
- 등산로 데이터: 산림청 공식 등산로
- 연료(숲 종류): 산림청 임상도

- 팀원과 기능별 브랜치로 협업 중이므로 feature/mountain-types 브랜치에만 작업
- 산림청 원본 자료는 이 작업 환경에서 받을 수 없어, 변환 도구를 만들고 같은 형식의 시험용 자료로 검증. 실제 자료는 사용자가 받아서 변환
